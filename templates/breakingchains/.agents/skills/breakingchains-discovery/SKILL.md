# Music discovery
- Inspect app/recommender.py, database schemas, favorites, dislike history and input sources.
- Rank transparent signals: subgenre, BPM confidence, artist diversity, novelty and user feedback.
- Prevent duplicates and artist monoculture; keep current filters functional.
- Never treat hashed video IDs as verified BPM or Camelot values.
- Test ranking on fixed offline fixtures before live crawling.

# BreakingChains UI/UX
- Read `static/index.html`, `static/style.css`, `static/app.js` and map dependent IDs.
- Preserve compact bottom player, sidebar state, views, musical metadata and favorites actions.
- Prefer incremental CSS design tokens with red `#ff1a1a`, charcoal surfaces and high-contrast typography.
- Check desktop/mobile in a real browser; preserve functionality and accessibility.
- Do not rewrite the audio engine for cosmetic work.

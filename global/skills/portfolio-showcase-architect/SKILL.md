# Arquitecto de Portafolios y Showcase Técnico

Esta skill ayuda a programadores a destacar visual y técnicamente frente a reclutadores y líderes de ingeniería a través de portafolios web, repositorios estelares y el README de perfil de GitHub.

---

## 1. Estructura de un Proyecto Estrella (Project Case Study)

Cada proyecto en el portafolio o GitHub debe documentarse como un **caso de estudio de ingeniería**, no como un simple repositorio:

### Plantilla de Documentación de Proyecto:
1. **Título y Propósito**: Qué problema real del mundo resuelve (ej. *"Sistema Kiosk de Venta Automatizada y Comunicación POS"*).
2. **Arquitectura y Stack**:
   * Diagrama Mermaid (`flowchart TD` o `sequenceDiagram`).
   * Tecnologías clave: Frontend, Backend, Base de Datos, Protocolos de Hardware.
3. **Desafíos Técnicos Superados (El corazón del proyecto)**:
   * Explicar el problema complejo (ej. *"Concurrencia en puerto serie RS232 de Transbank"*, *"Sincronización de audio en baja latencia con Web Audio API"*).
   * La solución técnica aplicada (mutex, pooling, buffering, streaming).
4. **Métricas y Resultados**: Impacto tangible, capturas de pantalla de la interfaz y enlace a la demo en vivo o video corto.
5. **Cómo ejecutar localmente**: Comandos limpios de instalación y prueba en Docker o local (`npm install`, `npm run dev`).

## 2. Optimización del GitHub Profile README (`username/username`)

Diseñar un perfil de GitHub magnético:
* **Encabezado**: Nombre, rol claro (*Full Stack Developer / Analista Programador*) y propuesta de valor única.
* **Tech Stack**: Badges limpios agrupados por Frontend, Backend, Bases de Datos, DevOps & Herramientas.
* **Proyectos Destacados (Pinned Repositories)**: Con descripciones directas, tags de tecnologías y links a demos.
* **GitHub Stats**: Widgets de actividad, lenguajes más usados y racha de commits.
* **Contacto**: Enlace a LinkedIn, correo profesional y enlace a descarga de CV en PDF.

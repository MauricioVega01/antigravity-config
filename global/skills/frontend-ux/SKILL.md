# Frontend UI/UX workflow
1. Inspect existing HTML/CSS/JS IDs, event bindings, rendering and navigation before modifying markup.
2. Define a minimal change plan and preserve all functional hooks.
3. Use reusable CSS tokens and semantic markup; ensure keyboard navigation and visible focus.
4. Verify desktop, tablet and mobile layouts and console warnings with actual browser tools when available.
5. Avoid arbitrary animations, decorative placeholders presented as live data, and unnecessary dependencies.
6. Report screenshots/tests actually performed.
